Замечания

Редактировать замечание

Изменения вступят в силу после нажатия «Сохранить». Затем выгрузи новый ZIP.

Передать обход

  1. Скачать — выбери формат, подготовь и скачай каждую часть ZIP.
  2. Найти файл — на iPhone: «Файлы» → «Загрузки» (iCloud Drive или «На iPhone», по настройкам Safari). На Android — «Загрузки».
  3. Передать / поделиться — выбери файл → «Поделиться» → Яндекс Диск или другой получатель. Для просмотра распакуй ZIP.

Записи останутся здесь. Отправка открывает меню передачи — загрузку проверь в самом Диске.

Готовь части по одной. При подготовке следующей предыдущую можно собрать заново; уже скачанный файл остаётся у тебя.
