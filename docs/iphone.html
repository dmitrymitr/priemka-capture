Приёмка на iPhone и iPad

Ревизия 2 · 1.1.2

Открыть приложение

Начало

  1. Открой приложение в Safari. Через «Поделиться» → «На экран Домой» добавь значок.
  2. Открой с интернетом и дождись сообщения об офлайн-готовности. До рабочего обхода проверь запуск в авиарежиме.
  3. В «Настройках» выбери личные значения по умолчанию. Они сохраняются при обновлении. Не удаляй данные сайта для обновления приложения.
  4. Создай обход: объект, специалист, раздел и первое помещение. По желанию включи типовые нарушения ПБ и съёмку подряд. Можно сразу добавить несколько PDF с планировками.

Обход

Сними фото, напиши или продиктуй описание микрофоном клавиатуры, нажми «Готово». Последние записи показываются сверху.

В режиме типовых нарушений введи короткое описание, например «замок на двери». Выбери подходящую полную формулировку из подсказок. Проверь смысл перед сохранением: приложение не подтверждает нарушение автоматически.

«Планы / PDF» открывает документы без выхода из обхода. Выбери PDF и нажми «Вернуться к обходу». Если встроенный просмотр неудобен, используй «Открыть / поделиться PDF». Загруженные PDF доступны без интернета.

Кнопка раздела сохраняет текущую запись в прежнем разделе и начинает новую в выбранном. Ранее сохранённые записи не меняются. Раздел отдельной записи можно изменить в её редакторе.

Съёмка подряд работает через встроенную камеру браузера: разреши доступ, нажимай «Снять фото», затем «Готово». Если камера не открывается, выбери «Обычная камера». После сворачивания повторно открой окно съёмки.

Текст новой записи автоматически сохраняется. После перезапуска открывается последний обход с черновиком. Дождись «Сохранено локально», особенно после фото. В редакторе сохранённой записи изменения нужно подтвердить кнопкой «Сохранить».

Фото в фототеку

В списке записей выбери «Сохранить фото в фототеку», либо в обзоре — «Фото обхода → фототека». Нажми «Поделиться фото» → «Сохранить изображения». Большие наборы разделены по 20 фото. При отсутствии системной команды открой отдельное фото и удерживай изображение для сохранения. Браузер не может записать фото в фототеку без твоего действия.

Завершение и ведомость

  1. Скачать. Нажми «Завершить обход», подготовь Excel и ZIP по каждому разделу. Скачай все части. При необходимости сначала нажми «Посмотреть / скачать Excel».
  2. Найти файл. Открой «Файлы» → «Загрузки» в iCloud Drive или «На iPhone», в зависимости от настроек Safari. Нажми ZIP для распаковки и открой XLSX в Excel.
  3. Передать / поделиться. Нажми «Поделиться» у ZIP, выбери Яндекс Диск или получателя. Проверь завершение передачи.

Название: «Объект_23.10.2026_ПБ_ч.1 из 3.zip». Внутри — только Excel-ведомость с фотографиями. Части нумеруются отдельно для каждого раздела. Повторная выгрузка после исправлений имеет то же имя: передавай актуальные части и проверяй, не добавил ли браузер суффикс к повторно скачанному файлу.

Ведомость содержит введённые описания, без автоматической проверки норм и исправления смысла. Одно замечание занимает одну строку. Каждое фото размещено поверх отдельной ячейки в своём столбце справа. Старое аудио не расшифровывается и не включается в Excel; в строке есть пометка о нём. PDF остаются в обходе.

Быстрый ZIP

В выгрузке можно выбрать исходники: JSON/CSV и папка media, без сборки Excel. PDF сохраняются отдельно. Части — до 25 замечаний или около 50 МБ, крупное одиночное замечание отдельно. Доступны прогресс и отмена.

Память

Настройки → «Память и удаление обходов». Удаление выбранного обхода убирает его записи, фото, аудио и PDF с устройства; другие обходы и настройки сохраняются. Перед удалением проверь нужные выгрузки и отдельно сохрани важные PDF/аудио. Excel-ведомость не является резервной копией приложения.

Данные хранятся локально на устройстве. Очистка данных Safari, удаление приложения или действия операционной системы могут удалить их. Регулярно передавай ведомости и нужные материалы.
