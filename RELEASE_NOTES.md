# Приёмка 1.1.1

- Excel: одно замечание — одна строка. Каждая фотография поверх отдельной ячейки в своём столбце «Фото 1», «Фото 2» и далее, справа от замечания.
- Добавлен номер «2» перед «Посмотреть / скачать Excel».
- PDF отображаются встроенным просмотрщиком без зависимости от PDF-плагина браузера: страницы, масштабирование, работа без интернета. Внешняя передача использует файл PDF через системное меню, а не ссылку blob.
- Кнопка возврата из PDF закреплена сверху.
- Увеличены расстояния между кнопками, в том числе в настройках, замечаниях, съёмке и выгрузке.

Установите APK поверх прежнего приложения, не удаляя его. Подпись проверяется на совпадение с предыдущими выпусками. Данные сайта Safari не очищайте.

Автоматически проверены отображение PDF, масштабирование, выгрузка файла, офлайн-просмотр, отступы и привязка шести фотографий к отдельным ячейкам одной строки Excel. Системное меню передачи и камера требуют проверки на реальном телефоне.
