# Приёмка — ревизия 2 (1.1.0)

- PDF-планы внутри обхода с быстрым возвратом к записи.
- Необязательные подсказки по 65 типовым нарушениям ПБ и съёмка нескольких фото подряд.
- Личные настройки сохраняются между обходами и обновлениями.
- Восстановление черновика, быстрая смена раздела, последние записи сверху.
- Передача фото в фототеку iPhone через системное меню «Поделиться».
- ZIP содержит готовую Excel-ведомость с фото по разделу. Имя: объект, дата, раздел, «ч.1 из 3».
- Пошаговая передача и выборочное удаление старых обходов с устройства.

Установите APK поверх прежней версии, не удаляя приложение. Подпись сверяется с 1.0.2. До обновления выгрузите нужные данные. Не очищайте данные сайта Safari.

Новый ZIP содержит только Excel: прежние аудио, PDF и исходные JSON в него не включены. Перед удалением обхода отдельно сохраните нужные материалы. В редакторе существующей записи нажимайте «Сохранить».

Браузерные тесты и проверка сохранности данных при обновлении пройдены. Перед рабочим обходом проверьте камеру, PDF, сворачивание и передачу файлов на своём устройстве. Реальный сценарий Safari/iPad требует проверки на устройстве.
