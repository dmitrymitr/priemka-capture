# Приёмка 1.1.2

- Возвращён быстрый исходный ZIP, выбран по умолчанию: observations.json, observations.csv и папка media с исходными фото и аудио. Совместимый формат priemka-capture/2, без запуска Excel и без перекодирования изображений.
- Готовая Excel-ведомость осталась отдельным вариантом выгрузки.
- Прогресс и отмена подготовки. Части по разделам: до 25 замечаний или примерно 50 МБ; очень большое одиночное замечание сохраняется целиком.
- ZIP обрабатывается небольшими блоками с паузами для интерфейса. В памяти остаётся одна подготовленная часть; при закрытии окна она освобождается.

PDF-планы сохраняются отдельно из «Планы / PDF». Используйте все части последней выгрузки. Исходный ZIP не восстанавливается автоматически в приложение. Данные обхода после выгрузки или отмены не удаляются.

Проверены исходные байты фото/аудио, JSON/CSV, целостность ZIP, отмена и повтор, разделение, отсутствие запуска Excel в быстром режиме, сохранение Excel-выгрузки. Фактическая скорость зависит от телефона и объёма данных.

Установите APK поверх прежней версии без удаления приложения. Подпись проверяется на совпадение. Данные сайта Safari не очищайте.
