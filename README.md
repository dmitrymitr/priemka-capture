# Приёмка — фото и голос

Веб-версия: https://dmitrymitr.github.io/priemka-capture/

## Android APK

Установочные файлы публикуются в разделе **Releases** этого репозитория. Скачай APK на телефон, открой его и, если Android запросит, разреши установку из используемого браузера. При первом использовании разреши камеру и микрофон.

APK содержит приложение внутри себя, поэтому первый запуск не требует интернета. «Передать обход · ZIP» открывает меню Android: выбери Яндекс Диск и нужную рабочую папку. Закрытие меню не подтверждает загрузку — проверь архив в самом Диске.

Записи в APK и браузере хранятся отдельно. До смены приложения выгрузи материалы из прежнего варианта. Удаление APK или очистка его данных удаляет локальные записи; перед этим выгрузи обход.

Сборка: `npm ci`, `npx cap sync android`, затем Gradle `assembleRelease` в каталоге `android`. В CI используются GitHub Secrets `ANDROID_KEYSTORE_BASE64` и `ANDROID_STORE_PASSWORD`. Ключ подписи не хранится в репозитории. Для обновления увеличивай `versionCode`/`versionName`, сохраняй `applicationId` и тот же ключ. Автоматическая сборка запускается вручную или по тегу `v*`; публикация APK выполняется отдельно после проверки результата.

Мобильный прототип для фиксации замечаний: фото → голос или текст → готово → следующая карточка.

Объект, специалист, раздел и зона запоминаются. Фото, аудио, черновик и завершённые карточки сохраняются в IndexedDB браузера. Приложение не отправляет материалы на сервер. Выгрузка — ZIP с JSON, CSV и исходными вложениями; архив загружается в рабочее хранилище отдельно.

## Запуск

Для GitHub Pages: ветка `main`, каталог `/docs`. Открой опубликованную HTTPS-ссылку в Chrome на Android. Первый запуск требует сети. После сообщения о готовности офлайн-режима проверь повторное открытие в авиарежиме.

Локальный запуск: `python -m http.server 8765 --bind 127.0.0.1 --directory docs`, затем `http://localhost:8765`. Обычный HTTP-адрес компьютера в локальной сети не подходит для доступа к микрофону телефона.

## Первый тест

1. Укажи учебный объект и имя.
2. Нажми «Фото», сделай снимок, подтверди в камере.
3. Нажми «Начать голосовую запись», проверь движение шкалы звука.
4. Продиктуй и нажми «Готово → следующее».
5. Сделай три записи, прослушай их через «Записано».
6. Выгрузи ZIP, проверь фото и звук на компьютере.

## Ограничения пилота

- При скрытии страницы аудиозапись останавливается. После звонка или блокировки проверь сохранённую часть.
- Данные привязаны к адресу сайта, браузеру и устройству. При смене адреса сначала выгрузи ZIP со старого сайта; автоматического переноса нет.
- Не используй инкогнито и не очищай данные сайта до выгрузки. Браузерное хранилище не заменяет резервную копию.
- Экспорт делится примерно по 150 МБ или 25 замечаний. Большое одиночное замечание не разделяется.
- JSON сохраняет исходные поля, CSV является реестром наблюдений. Расшифровка, проверка по документации и утверждение ведомости выполняются отдельно.
- На компьютере проверены тестовое фото, искусственный микрофон, завершение записи, восстановление черновика, ZIP и офлайн-запуск. Реальные Android-устройства и длительные обходы требуют испытания.

## Разработка

Приложение состоит из статических файлов и не требует сборки. При обновлении файлов увеличивай версию `CACHE` в `docs/sw.js`, чтобы обновить офлайн-копию. Не меняй имя IndexedDB без миграции пользовательских данных.
