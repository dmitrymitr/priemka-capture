# Приёмка — фото и замечания

## Ревизия 1 · 1.0.0

Фото → описание текстом (можно диктовать микрофоном клавиатуры) → готово. Отдельная аудиозапись удалена. Прежние аудиовложения сохранены и доступны для прослушивания и экспорта.

«Мои обходы» содержит активные и завершённые обходы. В обоих можно редактировать и удалять замечания, добавлять новые. Редактор позволяет менять текст и помещение, добавлять и убирать фото. Изменения применяются одной транзакцией после «Сохранить», отмена сохраняет исходную карточку. Удаление требует подтверждения.

- «Готово → ещё замечание здесь» сохраняет запись в текущем помещении.
- «Следующее помещение» сохраняет запись и начинает другое помещение.
- «Сохранить и к обзору обхода» сохраняет запись и открывает список помещений.
- «К обходу» сохраняет незавершённый черновик.
- «Завершить обход» сохраняет запись, возвращает на главный экран и предлагает ZIP.

После исправлений выгрузите все части ZIP заново. Уже переданные архивы не изменяются.

Веб-приложение: https://dmitrymitr.github.io/priemka-capture/

Инструкция для iPhone / iPad: https://dmitrymitr.github.io/priemka-capture/iphone.html

## Android

APK публикуется в Releases. Обновление 1.0.0 устанавливается поверх 0.2.0 с тем же applicationId и ключом подписи. Не удаляйте прежнюю версию: её локальные записи сохраняются при обновлении. Перед обновлением выгрузите резервный ZIP. Разрешение записи звука приложению больше не требуется; диктовку обеспечивает системная клавиатура.

APK содержит приложение и запускается без интернета. «Передать обход · ZIP» открывает системное меню, где можно выбрать Яндекс Диск. Проверяйте загрузку в самом Диске. APK и браузер используют отдельные хранилища.

## Данные и экспорт

IndexedDB `priemka-capture-v1`, схема 2; существующее хранилище сохраняется. Старые записи без tourId автоматически мигрируют с прежними ID, текстами и вложениями. Материалы не отправляются на сервер приложения.

ZIP: JSON, CSV и исходные вложения; разделение по 25 замечаний или примерно 150 МБ. Пустой обход можно экспортировать. В формате `priemka-capture/2` добавлены `appVersion`, `notes[].updated`, `tour.updated` и `deletedNotes` (список `{id, deletedAt}`, также внутри tour).

Для формирования ведомости предпочтительны все части последней выгрузки обхода. Если объединяются разные выгрузки, обновляйте записи по ID и updated; применяйте удаления из deletedNotes. Новые записи могут появиться после tour.completed: это историческое время завершения, а последующие изменения отмечены updated. Не трактуйте completed как подтверждение или устранение дефектов.

## Запуск и проверки

Статические файлы находятся в docs. Локально: `python -m http.server 8765 --bind 127.0.0.1 --directory docs`.

Тесты Playwright: `node tests/tours.cjs` и `node tests/revision1.cjs`. При необходимости задайте PLAYWRIGHT_MODULE. Проверяются переходы, миграция, офлайн-запуск, восстановление черновиков, редактирование, отмена, сбой записи, фотографии, удаления и экспорт. Реальная камера и диктовка клавиатуры проверяются на устройстве.

Android: `npm ci`, `npx cap sync android`, Gradle `assembleRelease lintRelease testReleaseUnitTest`. CI использует GitHub Secrets для существующего ключа подписи. Увеличивайте versionCode при обновлении APK и CACHE в docs/sw.js при изменении веб-файлов.
